# Proyecto 001 · Valeria

Pergamino interactivo, sin dependencias ni compilación. Abre `index.html` para verlo.

## Publicar con GitHub Pages

1. Crea un repositorio público llamado `Proyecto-Valeria` en tu cuenta de GitHub.
2. Sube `index.html` a la raíz y confirma el cambio en la rama `main`.
3. En el repositorio abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama **main**, carpeta **/ (root)** y pulsa **Save**.
6. Espera a que GitHub muestre el enlace publicado: `https://IIIIIIO-Beep.github.io/Proyecto-Valeria/`.

El nombre de usuario es el de la cuenta donde creas el repositorio. Si usas otro nombre de repositorio, cambia también ese segmento del enlace. La publicación puede tardar unos minutos.

## Interacción

Arrastra el borde inferior para revelar la carta. En pantallas pequeñas se desplaza automáticamente al acercar el dedo al borde inferior. También puedes usar los botones para abrir por partes o leer todo. El botón del pergamino funciona con teclado (Enter o espacio).

La carta es pública al publicar la página. No hay formularios, rastreadores ni servicios externos.
